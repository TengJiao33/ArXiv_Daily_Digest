## 我们真正关心什么

这个 radar 最有用的地方，是持续抓住和下面研究问题直接相关的论文：

- 真值性与事实性：幻觉、事实回忆、知识冲突、RAG 忠实性、声明验证、
  置信校准、拒答。
- 表示工程：残差流信号、activation steering、steering vector、probe、
  function vector、SAE 特征、干预。
- 机械可解释性：attention head、circuit、causal patching、logit lens、
  sparse autoencoder、可解码性与因果使用之间的区别。

如果一篇论文不完全属于配置里的方向，但提供了可以直接迁移到这些问题上的
方法或数据集，也值得保留。这不是“弱相关”，而是 `method-transfer`：
这类论文仍属于活跃语料。

重要区分：

- 应移除 / 隔离：明显离题，且没有贡献可复用方法、数据集、评测方式或局限性分析的论文。
- 应保留：虽然主题不在主线，但提供可复用机制，例如 probe、activation intervention、
  causal patching、SAE 分析、声明验证、校准指标、检索策略或 agent-memory 评测。

## 建议的活跃语料定义

近期 research-map 分析建议使用：

- `core`：直接关于 truthfulness、hallucination、faithfulness、内部表征、
  steering、mechanistic interpretability、RAG verification 或 agent memory safety。
- `method-transfer`：不直接研究 truthfulness，但方法可以复用于 probe、steering、
  activation patching、SAE 分析、声明验证、校准、检索策略或 agent-memory 评测。
  这也是活跃保留状态。

从活跃分析中排除：

- 目标领域是无线、金融、遥感、晶体生长、蛋白设计、语音 / TTS 或宽泛治理，
  且没有给当前研究问题提供可复用技术方法的 domain ML 论文。
